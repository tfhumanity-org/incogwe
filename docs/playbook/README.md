## The one-paragraph version

The product is the **legal request**, not the scan. Scanning tells you where someone is
listed on the public web; the statutory right is what makes a company act, and it works
against the brokers you cannot see — which are the ones holding the sensitive data.
Build the request engine first, make discovery a plug-in, and be ruthlessly honest about
what each outcome actually proves, because the whole category is currently reporting its
own dashboard back to itself and calling it a measurement.
